# Matt Yacoubian — Business Analytics Portfolio

Professional portfolio website hosted with GitHub Pages.
Live site: https://matt-hub-droid.github.io/portfolio/

## About this version
Cal Poly-inspired white, green and gold theme with:
- About Me and professional introduction
- Experience: MYDI LLC, Alpha Sigma Phi — Iota Chi, McDonald's
- Education and relevant coursework
- Certifications marked **In Progress** (not claimed as completed)
- Technical skills and filterable example project cards
- Resume placeholder and email-request link
- LinkedIn and Cal Poly contact email

## Edit your website
- `index.html`: content, navigation, resume, contacts, experience
- `styles.css`: colors, layouts, mobile styling
- `script.js`: interactive projects and placeholder descriptions
- `favicon.svg`: browser tab icon

## Add real projects
Replace placeholder details in `script.js` **only after a project is finished**.
For each real project, include the business question, tools, dataset source, methods, screenshots, results, and lessons learned.
Avoid exposing private customer or company data.

## Add your resume PDF
Upload a current public-safe resume PDF to the repository (for example, `resume.pdf`).
Then replace the disabled 'Resume PDF · Coming soon' text in `index.html` with:
`<a href="resume.pdf" class="button primary" download>Download Resume</a>`
Only enable this after uploading the file.

## Publish updates
Commit changes to the `main` branch. GitHub Pages is configured for `main` / root.
Changes appear after deployment. Refresh using Ctrl+Shift+R if necessary.

## Notes
This website is a student portfolio; example dashboard graphics and placeholder projects do not represent completed work.
